# Troubleshooting & Bug Reports

If you encounter unexpected behavior, enable the `Debug Logs` in `Settings`. Then, file an [Issue](https://github.com/tuxedocurly/wledger/issues/new) on GitHub or reach out on the [WLEDger Discord](https://discord.com/invite/wmDdcar7Kq).

:::info Pro Tip
Access your logs directly from the terminal for real-time monitoring:
`docker logs --follow wledger` (if deployed using Docker)
:::
